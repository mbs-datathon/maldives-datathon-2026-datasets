# Maldives Datathon 2026 – Datasets

**Mapping Mobility through Data: Innovating Transport Insights for a Connected Maldives**

Welcome to the official dataset repository for Maldives Datathon 2026.

This repository provides participants with access to datasets provided by Maldives Bureau of Statistics.

**Official Website:** https://www.datathon.stats.gov.mv/

## How to Access the Data

1. Click the download link for your preferred dataset.
2. Save the ZIP file to your computer.
3. Extract the ZIP file using Windows File Explorer, 7-Zip, or another extraction tool.
4. Open the extracted folder to access the data files.
5. Review any accompanying documentation before starting your analysis.

You can download either dataset individually or both datasets.
